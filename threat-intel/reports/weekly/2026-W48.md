*Coverage: 2026-11-18 to 2026-11-25. Auto-generated; summaries are AI-assisted.*

This week brought 13 additions to the CISA KEV catalog, one of them linked to ransomware, alongside 374 critical and 1,545 high-severity vulnerabilities. Known-exploited flaws were dominated by unauthenticated remote attacks: deserialization and object injection (Idunno AntiCsrf, Apache Roller), path traversal (MONAI Label), authentication bypass (VMware vCenter), and installer abuse (Drupal Core). Critical CVSS 10.0 issues centered on authentication and trust failures, including ASUS Control Center Express, HPE ArubaOS, Incus, and Miren Runtime, plus command injection in Mitel MiCollab and unrestricted file upload in Tegsoft Contact Center. By volume, Linux (130), Mozilla Firefox (72), and JetBrains TeamCity (68) led the vendor counts, with Mozilla Thunderbird, Adobe Campaign Classic, and Dell PowerStore models also prominent among affected technologies.

### Defender priorities

- Patch or mitigate the KEV-listed flaws first, especially internet-facing and management systems such as VMware vCenter, Drupal Core, Apache Roller, SAP NetWeaver, and MONAI Label.
- Prioritize CVSS 10.0 remote-access and authentication issues in ASUS Control Center Express, HPE ArubaOS, Mitel MiCollab, and Tegsoft Contact Center, and verify whether any are exposed externally.
- Inventory and update high-volume affected products, including Linux, Firefox, Thunderbird, TeamCity, and Dell PowerStore, and review whether any end-of-life components, such as Idunno AntiCsrf, remain in use.

## CISA KEV additions (13)

- **[CVE-2026-132224](/threat-intel/cve/CVE-2026-132224/)** — Optimizely Web Experimentation · CVSS 7.1
  Optimizely Web Experimentation's account signup flow allows external control of critical state data, letting an attacker impersonate existing customer users and modify Project JavaScript. That JavaScript is then served from Optimizely-hosted assets and runs in browsers of visitors to affected customer sites. It is known to be exploited.
- **[CVE-2026-131914](/threat-intel/cve/CVE-2026-131914/)** — Idunno AntiCsrf · CVSS 9.3
  Idunno AntiCsrf deserializes untrusted data, which lets an unauthenticated remote attacker achieve code execution via object injection. The product may be end-of-life or end-of-service, and the flaw is known to be exploited.
- **[CVE-2026-132165](/threat-intel/cve/CVE-2026-132165/)** — Drupal Core
  Drupal Core does not fail securely in its installer, so under specific conditions an unauthenticated attacker can use install.php to attempt to reinstall the site. This could lead to site takeover or arbitrary code execution, and it is known to be exploited.
- **[CVE-2026-133968](/threat-intel/cve/CVE-2026-133968/)** — Project MONAI MONAI Label · CVSS 9.8
  MONAI Label has a path traversal flaw that lets an unauthenticated remote attacker write arbitrary files outside the intended datastore directory. This can potentially result in remote code execution.
- **[CVE-2026-134624](/threat-intel/cve/CVE-2026-134624/)** — N-able MailAssure · CVSS 9.3
  The LDAP synchronization connection check in N-able MailAssure (SpamExperts) is vulnerable to SSRF. An authenticated API user can connect to arbitrary internal hosts and ports, learn which are reachable, and send crafted data to internal services. It is known to be exploited.
- **[CVE-2026-129448](/threat-intel/cve/CVE-2026-129448/)** — Apache Roller · CVSS 9.8
  Apache Roller's XML-RPC endpoint deserializes vendor extension types before authentication, allowing an unauthenticated remote attacker to execute arbitrary code. This CVE covers the same underlying flaw as CVE-2026-82384 but across a broader range of versions.
- **[CVE-2026-123890](/threat-intel/cve/CVE-2026-123890/)** — Broadcom VMware vCenter · CVSS 9.8
  VMware vCenter's Directory Service has an authentication bypass via an alternate path or channel, allowing an unauthenticated attacker with network access to gain unauthorized access to the system.
- **[CVE-2025-42884](/threat-intel/cve/CVE-2025-42884/)** — SAP NetWeaver · CVSS 6.5
  SAP NetWeaver Enterprise Portal fails to properly neutralize special elements in its data query logic, letting an unauthenticated attacker inject JNDI environment properties or a URL used during JNDI lookups. This can expose or alter server information, and it is known to be exploited.
- **[CVE-2026-76466](/threat-intel/cve/CVE-2026-76466/)** — Cisco Expressway Series · CVSS 9.8
  Cisco Expressway Series contains hard-coded credentials that let an unauthenticated remote attacker with persistent cookies and network access run commands as root on a clustered device via the database service.
- **[CVE-2026-90436](/threat-intel/cve/CVE-2026-90436/)** — Apache Axis · CVSS 9.8
  Apache Axis unsafely uses reflection when processing SOAP fault messages, letting an unauthenticated remote attacker cause it to load and instantiate an attacker-specified class if a suitable class is on the classpath. This can lead to arbitrary code execution, and the product may be end-of-life.
- **[CVE-2024-10441](/threat-intel/cve/CVE-2024-10441/)** — Synology DiskStation Manager (DSM) · CVSS 9.8 · 🔥 ransomware use
  Synology DSM's system plugin daemon (in BeeStation OS) improperly encodes or escapes output, allowing a remote attacker to execute arbitrary code via unspecified vectors.
- **[CVE-2026-40217](/threat-intel/cve/CVE-2026-40217/)** — BerriAI LiteLLM · CVSS 8.8
  BerriAI LiteLLM exposes an unprotected alternate channel at the /guardrails/test_custom_code URI that lets remote attackers execute arbitrary code via bytecode rewriting. It is known to be exploited, and Red Hat products that include LiteLLM are also listed.
- **[CVE-2026-90817](/threat-intel/cve/CVE-2026-90817/)** — Vanderbilt University Research Electronic Data Capture (REDCap) · CVSS 9.8
  REDCap has a code injection flaw where crafted HTTP requests reach an unintended controller route from a public survey context and supply a crafted file-path or stream parameter during data import processing. Exploitation requires a valid public survey hash, and it allows server-side code execution without authentication.

## Top critical CVEs (374)

- **[CVE-2026-114202](/threat-intel/cve/CVE-2026-114202/)** — ASUS Control Center Express · CVSS 10.0
  ASUS Control Center Express uses a hard-coded cryptographic key, so a remote user can forge an authentication token. This allows them to gain administrative privileges.
- **[CVE-2026-95787](/threat-intel/cve/CVE-2026-95787/)** — Hewlett Packard Enterprise (HPE) ArubaOS (AOS) · CVSS 10.0
  Vulnerabilities in the PAPI protocol of ArubaOS AOS-10 let an unauthenticated remote attacker bypass authentication controls. Successful exploitation can give administrative access, allow configuration changes, and expose or alter sensitive data.
- **[CVE-2026-130778](/threat-intel/cve/CVE-2026-130778/)** — lxc incus · CVSS 10.0
  Incus accepts a TLS client chain with a trusted certificate appended, letting remote attackers authenticate as any trusted certificate, such as the server's or a cluster member's. This enables cluster-level access, authorization bypass, trust store modification, and influence over scriptlet-based authorization decisions.
- **[CVE-2026-71499](/threat-intel/cve/CVE-2026-71499/)** — hefy2027 cf-manager · CVSS 10.0
  cf-manager fetches user-supplied URLs without protocol, destination, redirect, content-type or size validation and deploys the returned content as a Cloudflare Worker script using stored credentials. An attacker with deployment access could abuse this to fetch arbitrary content and deploy it.
- **[CVE-2026-75521](/threat-intel/cve/CVE-2026-75521/)** — mirendev runtime · CVSS 10.0
  The Miren Runtime QUIC/HTTP3 RPC server (default port 8443) requests client certificates but does not verify they chain to the cluster certificate authority. Caller identity is taken from the certificate's Common Name, and certificate identities bypass RBAC checks, so an unverified certificate can gain trusted access. The provided description is truncated.
- **[CVE-2026-133323](/threat-intel/cve/CVE-2026-133323/)** — Mitel MiCollab · CVSS 10.0
  The Audio, Web, and Video Conferencing (AWV) component of Mitel MiCollab has insufficient parameter sanitization, allowing an unauthenticated attacker to perform blind command injection and run arbitrary commands on the system. Tracked by Mitel as MTLVULN-1864.
- **[CVE-2026-77312](/threat-intel/cve/CVE-2026-77312/)** — flytohub flyto-core · CVSS 10.0
  Flyto2 Core's earlier fix for CVE-2026-67429 applied path validation to only some file-writing modules, leaving data.csv.write, data.json_to_csv, file.copy, and file.move outside the FLYTO_SANDBOX_DIR confinement. These modules can therefore operate on paths beyond the intended sandbox.
- **[CVE-2026-14914](/threat-intel/cve/CVE-2026-14914/)** — Tegsoft Yönetim ve Bilişim Hizmetleri Tic. Ltd. Şti. Tegsoft Contact Center · CVSS 10.0

- **[CVE-2026-62841](/threat-intel/cve/CVE-2026-62841/)** — Microsoft Azure Event Grid System · CVSS 10.0
